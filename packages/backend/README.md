## HanamiSearch v2 のカーソル暗号鍵

HanamiSearch v2 を使うには、設定ファイルの `hanamisearch.cursorEncryptionKey` に専用の256ビット鍵を64桁の16進数文字列として設定します。暗号学的擬似乱数生成器でAPIキーとは独立して生成してください。生成コマンドの例は `openssl rand -hex 32` です。APIキーやそのハッシュ、人が決めた文字列を流用しないでください。設定の検証は形式と長さのみで、乱数の品質は保証しません。

鍵は秘密情報として管理し、同じインスタンスの全バックエンドプロセス・レプリカへ同じ値を配布してください。再起動後も値を維持し、リポジトリやログへ記録しないでください。未設定・空欄・不正な形式の場合、HanamiSearch v2 の検索は `UNAVAILABLE`（HTTP 503）を返します。HanamiSearch v1 とバックエンドの起動にはこの鍵は不要です。

鍵を変更すると、それまでに発行したカーソルは `INVALID_CURSOR` になり、最初から検索し直す必要があります。APIキーのSHA-256ハッシュを暗号鍵としていた版からの更新でも既存カーソルは引き継ぎません。旧鍵による復号へのフォールバックはありません。
